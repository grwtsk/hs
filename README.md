# Hs

Haas, Hospital, or House: sanctuary, care, and communion.

The [program](https://github.com/grwtsk/hs/issues/1) tracks the philosophical book
and its later interface. The source archives are documented in
[sources/README.md](sources/README.md), including the
[later refinements and proposal boundaries](sources/conversation/02-reading-guide.md).

This repository does not yet contain the completed book or interface.
[Open disagreements](https://github.com/grwtsk/hs/issues/66) retain their human
owners. Preserving a source does not resolve them or accept the philosophy.
