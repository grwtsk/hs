# Front matter commission

Issue #16 includes half-title, title, rights/edition information, approved optional
dedication, epigraph and foreword, preface, reader's note, contents and lists.
The byline, external contributors, permissions and optional omissions remain
human choices in #6. Do not invent them. The edition record marks every item;
no generated title page or empty file is counted as completed front matter.

The [reader's note](readers-note.md) is an agent-provisional approach to reading
Hs, written to test how its argument can remain open without becoming evasive.
It is not a claimed fresh reading of the full Huey manuscript or external books.
