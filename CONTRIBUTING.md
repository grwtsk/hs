# Contribution and review

Begin with [AGENTS](AGENTS.md) and [RESUME](RESUME.md). Work from verified current
main after the existing PR queue permits. Preserve dirty work. Keep the source
archive and original PNG outside unrelated changes.

A contribution names its actual issue and bounded output, source versions read,
attribution and approval scope. Research references are not execution
prerequisites. Work records use separate preparation and disposition nodes for
human issues; completing a packet does not answer it. The recorded graph is the
stage-level foundation, not a claim to have audited every detailed issue's
prerequisites. Read that issue before executing it.

New prose must develop an argument, a serious objection, an example and a
consequence. Label agent-authored drafts and map material DGs beside the passage.
No placeholder counts as a chapter. The [edition record](planning/edition.json)
keeps the full commission visible, including optional matter needing an explicit
human disposition. Reconcile a changed source through the reading ledger; do not
rewrite original passages or earlier execution receipts.

Run [the local validation command](validation/README.md). Use synthetic fixtures.
Review meaning, rights, source fidelity and accessibility obligations separately
from structural tests. The JSON subset of YAML used for disagreements avoids a
runtime YAML dependency; duplicate keys and nonfinite values fail validation.

Before opening the sole work PR, inspect the staged diff, commit identities and
remote result. Include commands and observed outcomes, including failures and
unrun checks. Avoid automatic issue-closing keywords unless the entire issue is
actually complete. A passing foundation check does not justify closure of #5's
wider editorial integration or #66's ongoing disagreement work.

The submitter must not impersonate independent review or human acceptance.
The reviewer distinguishes actual defect correction from a human-owned normative
choice. No change to G1/G2/G3 or wider permissions follows from approving code.
